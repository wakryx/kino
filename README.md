# Кино вдвоём

Сайт, чтобы смотреть фильмы вместе на расстоянии. Работает напрямую браузер-в-браузер (WebRTC), без своих серверов, бесплатно на GitHub Pages.

## Режимы

| Режим | Когда | Качество |
|---|---|---|
| **Синхронно** | Фильм есть у обоих (файл или прямая ссылка на .mp4) | Оригинальное, хоть 4K. По сети идут только команды «пауза/play/перемотка» |
| **Передать файл** | Фильм только у одного | Оригинальное. Файл передаётся напрямую, потом включается «Синхронно» |
| **Трансляция** | Ждать некогда | До 40 Мбит/с, до 60 fps, стерео-звук. Зависит от скорости отдачи того, кто показывает |

Ещё есть чат, голос и камера («свой Телемост»), полноэкранный режим с уведомлениями из чата, субтитры .srt/.vtt (в том числе в кодировке Windows-1251).

## Как выложить на GitHub Pages

1. Зарегистрируйся на https://github.com и нажми **New repository** (например, `kino`), тип **Public**.
2. На странице репозитория: **Add file → Upload files** и перетащи туда файлы `index.html`, `style.css`, `app.js` и папку `vendor` (с `peerjs.min.js`). Нажми **Commit changes**.
3. **Settings → Pages → Branch: `main`, папка `/ (root)` → Save**.
4. Через 1–2 минуты сайт откроется по адресу `https://ТВОЙ_НИК.github.io/kino/`.

## Как пользоваться

1. Один нажимает «Создать комнату» и отправляет ссылку второму.
2. Второй открывает ссылку и жмёт «Войти».
3. Вверху должно появиться «… в комнате» и метка «напрямую (P2P)».

## Если не подключается (актуально для России)

- Библиотека PeerJS лежит в `vendor/`, а не на CDN: Cloudflare в России замедляют.
- «Знакомство» браузеров идёт через бесплатный сервер `0.peerjs.com`. Если он недоступен, можно бесплатно поднять свой PeerJS-сервер (например, на Render.com) и указать его в «Настройках соединения».
- Если метка показывает, что соединение не установилось, нужен TURN-сервер (ретранслятор). Бесплатный тариф есть, например, у metered.ca. Логин и пароль введите в «Настройках соединения» **у обоих**. Через TURN трансляция ограничена его трафиком, поэтому лучше использовать «Передать файл» / «Синхронно».

## Советы

- Лучшие браузеры: Chrome, Edge, Яндекс Браузер на компьютере. Safari и телефоны работают хуже (особенно трансляция).
- MKV со звуком AC3/DTS браузер может проиграть без звука. Тогда лучше взять MP4 (H.264 + AAC).
- Для трансляции выбирай битрейт меньше своей скорости **отдачи** (проверить: speedtest.net → Upload).
- Говорите в наушниках, чтобы звук фильма не попадал в микрофон.
